# Volta Elite Academy

Premium school website for Volta Elite Academy, Ho, Volta Region. Built with Next.js, TypeScript and Tailwind CSS. All content is static. Forms stay in the browser and are not sent anywhere.

## Run

```bash
npm install
npm run dev
npm run build
```

Open [http://localhost:3000](http://localhost:3000).

## Photographs

Add JPG files to `public/images/` using the filenames listed in the project brief. Until those files are present, each image area shows a blue gradient. Replace the SVG files in `public/brand/` with finished artwork when it is ready; the same filenames are already wired up.
